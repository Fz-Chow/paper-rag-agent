# 双跳任务集

`two_hop_demo.jsonl` 提供 8 道封闭世界合成题（探索 4、验证 4），仅用于跑通流程；题内人物、项目和来源均为虚构。来源编号指向题内材料，不是可访问的外部资料。全部人工核验状态为 pending，不能作为正式研究结果。

人工审核每题两跳关系、唯一答案、别名、干扰材料是否泄露答案，并核对来源后，将 `human_review.status` 设为 `verified`，填入 `reviewer` 和 ISO 日期 `reviewed_at`。真实任务应另建数据文件，填写可追溯来源。同一事实组合和其改写必须共用 `fact_group` 并进入同一 split；校验器还能检测完全相同必要证据文本的跨划分泄漏，语义改写仍需人工检查。

每题需有偶数个材料块（至少 4），恰好 2 个必要证据编号。所有条件使用同一来源标记。集中/分散不增加、删除或改写文本；必要证据条件是较短的能力检查，不参与等长对照。

正式验证前固定数据、规则和模型 revision，使用新的输出目录。验证集禁止 `--allow-unreviewed`。题量很小，排列不能当作独立题目计算样本量，不能据此宣称普遍规律。
